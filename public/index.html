Documentación Básica de la API

POST /api/v1/reseller/ssh/create

Crea o encola una cuenta SSH en un VPS asignado. (0 GB = Ilimitado)

curl -X POST https://sv-free.joif.net/api/v1/reseller/ssh/create \
  -H "Authorization: Bearer ${apiKey}" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "usuario_api",
    "password": "mi_password_segura",
    "connection_limit": 2,
    "gb_limity": 1,
    "expiration_days": 30,
    "vps_id": "usa-01"
  }'
GET /api/v1/reseller/ssh/info/:username

Obtiene el consumo de banda ancha en tiempo real, límite y conexiones activas.

curl -X GET https://sv-free.joif.net/api/v1/reseller/ssh/info/usuario_api \
  -H "Authorization: Bearer ${apiKey}"
GET /api/v1/reseller/ssh/list

Lista todas las cuentas SSH creadas por ti.

curl -X GET https://sv-free.joif.net/api/v1/reseller/ssh/list \
  -H "Authorization: Bearer ${apiKey}"
DELETE /api/v1/reseller/ssh/delete/:username

Elimina permanentemente una cuenta de tu clúster.

curl -X DELETE https://sv-free.joif.net/api/v1/reseller/ssh/delete/usuario_api \
  -H "Authorization: Bearer ${apiKey}"
